# lupack-lancelot

This repository is for the edition _Lancelot of the Laik and Sir Tristrem_, edited by Alan Lupack. It contains:

- TEI-XML files of the digital edition. Last file updated: 11/20/2026.

- A PDF of the entire edition. Current version: 11/20/2026

- A Corrections Log, where we record all typographic and editorial corrections made. Current version: 11/20/2026
